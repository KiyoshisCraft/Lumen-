# Lumen

Editor de fotografia no navegador, inspirado no Lightroom. Funciona 100% offline: as fotos nunca saem do teu dispositivo.

## Ferramentas

- Básico: temperatura, tonalidade, exposição, contraste, realces, sombras, brancos, pretos, textura, clareza, remover névoa, vibração, saturação, conta-gotas de brancos
- Curva de tons (RGB, R, G, B)
- Cor (HSL) em 8 cores
- Detalhe: nitidez e redução de ruído
- Efeitos: vinheta e grão
- Filtro graduado
- Recorte: endireitar, proporções, rodar, espelhar
- Histograma, antes/depois, predefinições, copiar/colar definições
- Importação em lote e exportação em JPG, PNG ou WebP (resolução total)

## Como usar

**Local:** abre o `index.html` no navegador (duplo clique). Não precisa de servidor nem de instalação.

**Online (GitHub Pages):** Settings > Pages > Source: `main` / root. O app fica em `https://SEU-USUARIO.github.io/NOME-DO-REPO/`.

## Limitações

- Não abre RAW (CR2, NEF, ARW). Exporta para JPG/TIFF antes.
- As edições não são guardadas ao fechar a página. Exporta antes de sair.

## Estrutura

Tudo está em `index.html` (HTML, CSS e JS, sem dependências).
